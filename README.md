Entry for the [Make.fun One Emoji, One Smile bounty](https://make.fun/bounty/u-0xkianno-one-emoji-one-smile-5470751f): send exactly one emoji, the one most likely to make a stranger smile.

## The entry

🤗

A hugging face — warm at first glance, friendly to any stranger, and chosen rather than the default smiley.

## How it works

`main.py` writes that single emoji to `/output/entry.txt` — nothing else, no words, no caption, no explanation.

```sh
python3 main.py
```
